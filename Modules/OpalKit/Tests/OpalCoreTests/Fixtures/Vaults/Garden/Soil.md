# Soil

Soil is a mix of sand, silt, clay and organic matter.

| Type | Drains | Holds nutrients |
| ---- | ------ | --------------- |
| Sand | Fast   | Poorly          |
| Clay | Slow   | Well            |
| Loam | Even   | Well            |

Compost improves every kind. ^compost-rule

Tomatoes need rich soil, as Gardening Basics says.
